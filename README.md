# KOLVIKA jewelry — лендинги

Приватный репозиторий для рекламных и сервисных лендингов KOLVIKA jewelry.

## Структура

- `landings/custom-jewelry/` — лендинг «Изготовление украшений на заказ».
- В каждом следующем лендинге храним собственные исходники, изображения и настройки публикации в отдельной папке внутри `landings/`.

## Текущий лендинг

Внутри `landings/custom-jewelry/dist/` находится готовая статичная версия страницы. Изображения расположены в `dist/assets/`.
